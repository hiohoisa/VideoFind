# VideoFind 最终用户 Demo

VideoFind 帮助用户用自然语言搜索视频内容，并返回答案所在的时间段、摘要和可核验的原文依据。

演示字幕：`demo/sample_subtitles.srt`

## 案例一：正确搜索

### 输入

**用户问题**

> 简历项目经历怎么写？

### 系统处理

1. **Semantic Retrieval**：将问题和字幕片段编码为向量，召回最相关的片段。Top1 位于 `03:18–04:12`，相似度分数为 `0.7407`。
2. **Answerability**：综合 Top1 分数、Top1/Top2 分差和关键词覆盖率，判断视频中存在可靠答案。

### 输出

- **时间戳**：03:18–04:12
- **摘要**：项目经历应写清个人负责的内容、采取的行动和最终结果，并按照 STAR 结构组织。
- **原文依据**：“项目经历是简历最重要的部分。不要只写参与了某项目，要说清楚你负责什么、采取了什么行动，以及最后带来了什么结果。可以按背景、任务、行动、结果，也就是 STAR 的顺序来写。”

## 案例二：同义搜索

### 输入

**用户问题**

> 怎样在履历中体现自己的贡献？

### 系统处理

1. **Semantic Retrieval**：识别“履历”“自己的贡献”与“简历项目经历”“负责什么”的语义关联。Top1 位于 `03:18–04:12`，相似度分数为 `0.6712`。
2. **Answerability**：虽然问题没有复用字幕原词，但 Top1 语义分数和候选分差满足判断条件，因此接受该结果。

### 输出

- **时间戳**：03:18–04:12
- **摘要**：在履历中突出个人贡献时，应明确说明自己的职责、行动和结果，而不是只写“参与了项目”。
- **原文依据**：“不要只写参与了某项目，要说清楚你负责什么、采取了什么行动，以及最后带来了什么结果。”

## 案例三：无答案拒答

### 输入

**用户问题**

> 产品经理需要什么能力？

### 系统处理

1. **Semantic Retrieval**：检索到的候选片段最高相似度仅为 `0.4170`，且字幕没有直接讨论产品经理的能力要求。
2. **Answerability**：Top1 分数未达到默认阈值 `0.50`，关键词证据也不足，系统判定视频中不存在可靠答案。

### 输出

> 未找到与该问题高度相关的视频内容

系统不会为无答案问题强制生成时间戳、摘要或原文依据。
